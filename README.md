# Classic Barbershop — Omaha, NE

A single-page website for **Classic Barbershop** at 3930 N 90th St, Omaha,
Nebraska — traditional men's and kids' haircuts, hot-lather straight-razor
shaves and clean neck lines. Walk-ins welcome; booking via Booksy.

Built with plain HTML, CSS and JavaScript — no build step. Open `index.html`
in a browser, or serve the folder with any static file server.

## Facts & sources

Business details (address, phone, hours, services, rating) come from public
listings (Yelp, Booksy, BestProsInTown, YellowPages). The shop's 4.8★ / 127
reviews figure is the aggregate from public review sources. No customer quotes
are invented; the site uses the verified aggregate rating and the shop's
described services in place of unverifiable testimonials.

Photos are stock placeholders (Pexels) intended to be replaced with the
shop's own photos.
